# dev-team-hub

Portal colaborativo del equipo de desarrollo, construido en Markdown como parte del Taller de Git y GitHub.

## Integrantes

## Estructura del proyecto

- `equipo/` - fichas individuales de los miembros del equipo
- `recursos/` - herramientas y buenas practicas recomendadas

## Reglas de trabajo

1. Nunca hacer commits directos en `main`.
2. Crear una rama descriptiva por cada tarea (`feat/...`, `fix/...`, `docs/...`).
3. Enviar los aportes mediante Pull Request y revision de codigo.
4. Eliminar las ramas ya fusionadas.
